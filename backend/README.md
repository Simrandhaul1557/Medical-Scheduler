# Medical Scheduler Backend

NestJS backend API for the Medical Scheduler application.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run start:dev
```

The API will be available at http://localhost:3001

## API Endpoints

- `GET /` - Returns "Hello World from NestJS Backend!"

## Build

To create a production build:
```bash
npm run build
npm run start:prod
```
